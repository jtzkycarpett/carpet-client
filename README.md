# Carpet Client
Minecraft launcher with Fabric support.

## Get the installer (no Node.js needed on your PC)
1. Upload this folder to a new GitHub repository.
2. Open the Actions tab, pick "Build Carpet Client", click "Run workflow".
3. When it is done, download the installer from the run's Artifacts.

For a public download page: create a tag like v0.1.0. The installers
(.exe / .dmg / .AppImage) then appear under Releases automatically.

## Development
npm install && npm start
